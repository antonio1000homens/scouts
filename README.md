# Scout Group Website

A professional, responsive website for a Scout Group with a clean and modern design inspired by scout organization websites.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Section Information**: Dedicated pages for Beavers (6-8), Cubs (8-10½), Scouts (10½-14), and Explorers (14-18)
- **News Section**: Display latest updates and announcements
- **Contact Form**: Easy way for interested families to get in touch
- **Scout Branding**: Uses official scout colors (purple, teal, green, blue)
- **Sticky Navigation**: Easy navigation throughout the site
- **Modern UI**: Clean, professional design with smooth animations and hover effects

## Structure

- `index.html` - Main HTML file with all page content
- `styles.css` - Complete styling with responsive design
- Sections include:
  - Home/Hero section with call-to-action
  - About section
  - Our Sections (Beavers, Cubs, Scouts, Explorers)
  - Latest News
  - Contact information and form
  - Footer

## How to Use

Simply open `index.html` in a web browser, or serve it using any web server:

```bash
# Using Python
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```

## Customization

To customize for your specific scout group:

1. Update the group name in `index.html` (search for "Scout Group")
2. Modify meeting times and locations in the sections
3. Update contact information (email, phone, address)
4. Add your own news items and events
5. Customize colors in `styles.css` if needed

## Technologies

- HTML5
- CSS3
- No JavaScript dependencies - pure HTML/CSS for maximum compatibility and performance
